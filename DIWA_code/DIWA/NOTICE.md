# Source provenance

This delivery was assembled from the existing DIWA project supplied with the manuscript. It retains its DreamVLA integration and source attribution. The original project README is preserved as `UPSTREAM_README.md` (its optional media assets are not part of this code package).

DreamVLA upstream: <https://github.com/Zhangwenyao1/DreamVLA>.

The action-model files retain their original references and copyright headers for DiT and OpenAI diffusion implementations. Those components, and separately installed encoders/simulators, retain their respective upstream licensing terms. This package does not assign a new blanket license to third-party code.

The standalone feature workflow, shared influence helper, configuration files, regression tests and delivery documentation were added while organizing the manuscript reference code. No paper-trained weights or recorded robot trajectories are bundled. Generated CPU examples are explicitly marked `synthetic_fixture` and are excluded from experimental claims.
